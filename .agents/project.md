# diff-guard

Локальный AI-аудитор Git Diff для фронтендеров с генеративным UI. Пользователь
загружает `.diff`/`.patch` файл, расширение анализирует его прямо в браузере
(без сети, без бэкенда) и строит интерактивные виджеты: инлайн-карточки ревью,
песочницу для CSS/SCSS-анимаций с метриками FPS, советы по UX/производительности.

## Принципы

- **Local-first**: весь инференс идёт на устройстве пользователя. Diff и код
  никогда не покидают браузер — это ключевое УТП продукта, не нарушать.
- **WebGPU / WebLLM**: модель грузится и исполняется через
  [WebLLM](https://github.com/mlc-ai/web-llm) поверх WebGPU. Если WebGPU
  недоступен — приложение должно явно сообщать об этом, а не молча падать.
- **Генеративный UI**: ответ модели парсится в структурированные блоки, из
  которых на лету собираются Svelte-компоненты (карточки, песочницы), а не
  просто markdown-текст.
- **Manifest V3**: расширение живёт как Chrome Extension (Side Panel), без
  persistent background — только event-driven service worker.
- **File System Access API**: используется для локальной загрузки diff-файлов
  и (в перспективе) чтения файлов проекта для более богатого контекста ревью.

## Стек

- Svelte 5 (Runes) + TypeScript (strict) + Vite
- `@crxjs/vite-plugin` (или аналог) для сборки Chrome Extension MV3
- WebLLM (`@mlc-ai/web-llm`) как движок инференса на WebGPU
- Никакого бэкенда, никаких внешних API-вызовов с пользовательским кодом

## Цели MVP

1. Загрузка `.diff`-файла (drag-n-drop / file input) и raw-просмотр содержимого.
2. Инициализация WebLLM-модели с индикацией прогресса загрузки весов.
3. Промпт, который просит модель вернуть структурированный (JSON) разбор diff:
   список замечаний с привязкой к строкам/файлам.
4. Рендер замечаний как инлайн-карточек рядом с соответствующими строками diff.
5. Песочница для CSS/SCSS-анимаций (iframe-изоляция) с измерением FPS.

## Структура AI-инструкций

- `.agents/skills/` — best practices по технологиям (Svelte 5, Chrome
  Extension MV3, TypeScript).
- `.agents/tools/` — рутинные команды (сборка, dev, загрузка расширения).
- `.agents/harness/` — ограничения и правила безопасности для AI-агентов.
