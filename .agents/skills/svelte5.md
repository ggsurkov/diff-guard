# Svelte 5: правила для этого проекта

Проект использует **только** новую реактивность Svelte 5 (Runes). Код на
синтаксисе Svelte 4 недопустим, даже если он всё ещё компилируется.

## Разрешено

- `let x = $state(initial)` — реактивное состояние вместо `let x = initial`.
- `$derived(expr)` / `$derived.by(() => {...})` — вычисляемые значения вместо `$: y = ...`.
- `$effect(() => {...})` — побочные эффекты вместо `$: { ... }` с side-эффектами.
  Возвращай функцию очистки, если effect подписывается на что-то внешнее.
- `let { prop, children }: Props = $props()` — вместо `export let prop`.
- `$bindable()` — для пропсов с двусторонним биндингом вместо `export let` + `bind:`.
- Снапшоты состояния через `$state.snapshot(x)`, когда нужен plain-объект (например, для `JSON.stringify` перед вызовом WebLLM).
- Именованные слоты и `{#snippet ...}` вместо `<slot>` там, где нужна параметризация.

## Запрещено

- `export let prop` для пропсов компонента.
- `$: reactiveStatement` в любой форме.
- `<slot>` — использовать snippets.
- Svelte stores (`writable`/`readable`) для локального состояния компонента —
  только когда состояние действительно должно жить вне дерева компонентов
  (например, глобальный статус WebLLM-движка), и даже тогда предпочитать
  `.svelte.ts`-модуль с `$state` в classе/объекте, а не classic store.
- Мутация пропсов напрямую без `$bindable()`.

## Типизация компонентов

```ts
interface Props {
  diffText: string;
  onAnalyze?: (result: ReviewResult) => void;
}
let { diffText, onAnalyze }: Props = $props();
```

## Эффекты и WebGPU/WebLLM

- Инициализация тяжёлых объектов (WebLLM engine, WebGPU-контекст) — в
  `$effect`, с обязательной очисткой (`return () => engine.unload()` и т.п.),
  чтобы при закрытии side panel не оставались висящие GPU-ресурсы.
- Не запускай генерацию модели внутри `$derived` — только внутри `$effect`
  или обработчика события, `$derived` должен оставаться чистой функцией без
  побочных эффектов.

## Файлы

- Компоненты: `*.svelte`.
- Реактивные модули без разметки (сторы состояния приложения, WebLLM-клиент):
  `*.svelte.ts`, чтобы можно было использовать руны вне `.svelte`-файлов.
